**영문 제목 제안**

* Escape Zzuggur
* Zzuggur: Office Escape
* Project Zzuggur

장르: 탑다운 쯔꾸르 스타일 / 방탈출 / 미니퍼즐
플레이타임: 약 8~10분
플랫폼: Web (React / Phaser 등)

---

## 1. 게임 스토리

플레이어는 어느 날 밤, 텅 빈 사무실 건물 안에서 눈을 뜬다.
출입문은 잠겨 있고, 메인홀 중앙에는 잠금 상자가 하나 놓여 있다.

> 시스템: “출입문은 잠겨 있다.”
> 시스템: “어딘가에 열쇠가 있을 것 같다.”

건물 안의 각 방에는 이전 근무자들이 남긴 장치와 퍼즐이 있고,
이를 하나씩 해결해 숫자 메모를 모아야만 상자를 열 수 있다.

모든 것은 과하게 심각하지 않되, 어딘가 묘하게 불길한 분위기를 유지한다.

## 3. 게임 진행 방식 및 클리어 조건

### 기본 진행 방식

1. 메인홀에서 각 방으로 자유 이동
2. 방 안의 특정 오브젝트에 닿으면 미니퍼즐 시작
3. 미니퍼즐은 전체 화면으로 전환되어 단독 진행
4. 클리어 시 숫자 메모 1개 획득
5. 숫자 3개를 모두 모아 메인홀 상자 해금
6. 열쇠 획득 후 출입문으로 이동 → 클리어

### 실패 처리

* 미니퍼즐 실패 시 즉시 재도전 가능
* 게임 오버 없음

## 4. 엔딩 분기

### Happy Ending (완전 탈출)

**조건**: 모든 미니퍼즐 클리어 후 탈출

* 텍스트: "문이 열린다. 밖의 공기가 느껴진다. 오늘 야근은 여기까지다."

### Neutral Ending (대충 탈출)

**조건**: 힌트 확인 후 최소 정보만으로 탈출 (선택 요소)

* 텍스트: "나오긴 했지만… 뭔가 찜찜하다."

### Bad Ending (포기)

**조건**: 일정 시간 경과 후 포기 선택

* 텍스트: "불이 꺼진다. 내일도 출근일지도 모른다."

## 7. 미니퍼즐 상세 스펙

### 미니퍼즐 A – 패턴 기억 퍼즐 (회의실)

* 화면: 단계별로 격자 크기 변경 (바둑판 형태, 간격 없음, border 있음)
* 진행 방식: 3단계 순차 진행
  * 1단계: 3×3 격자, 3개 셀 점등 (위치 랜덤, 순차 점등)
  * 2단계: 4×4 격자, 5개 셀 점등 (위치 랜덤, 순차 점등)
  * 3단계: 5×5 격자, 7개 셀 점등 (위치 랜덤, 순차 점등)
* 규칙:
  1. 각 단계마다 셀이 순차적으로 하나씩 점등 (노란색, 1초간 유지 후 다음 셀)
  2. 모든 패턴 표시 후 전부 꺼짐
  3. 플레이어가 같은 패턴을 순서대로 클릭 (같은 셀이 여러 번 점등될 수 있음)
  4. 한 단계 성공 시 1초 대기 후 다음 단계 진행 (카운트다운: 3 → 2 → 1 → START)
  5. 실패 시 실패 메시지 + 재시도/나가기 버튼 (1단계부터 재시작)
* 성공 조건: 3단계 모두 완료 (패턴 완전 일치)
* 실패 조건: 오입력 (단계별 실패, 1단계부터 재시작)
* 실패 처리: 
  * 실패 메시지 표시
  * 재시도 버튼 (게임 초기화 후 1단계부터 재시작)
  * 나가기 버튼 (탐험 씬으로 복귀)
* 성공 처리:
  * 성공 화면 표시
  * 보상 숫자를 애니메이션과 함께 표시 (파란색 사각형, 흰색 글씨)
  * 나가기 버튼만 표시 (E키 또는 클릭)
* 시각적 요소:
  * 점등 색상: 노란색
  * 셀 배경색: 구분감 있도록 (어두운 색)
  * 셀 border: 구분을 위한 테두리
  * 셀 크기: 화면에 맞게 적절히
* 보상: 숫자 메모 1개

---

### 미니퍼즐 B – 타이밍 퍼즐 (창고)

* 화면: 가로 바 + 이동 포인터
* 진행 방식: 3단계 순차 진행
  * 1단계: 성공 영역 30%, 포인터 속도 200px/s
  * 2단계: 성공 영역 20%, 포인터 속도 300px/s
  * 3단계: 성공 영역 10%, 포인터 속도 400px/s
* 규칙:
  1. 포인터가 가로 바를 좌우로 왕복 이동 (무한 반복)
  2. PC/모바일 모두 화면 내 아무 영역 클릭/터치 시 정지 (나가기 버튼 제외)
  3. 성공 영역 위치는 각 단계마다 랜덤 (가로 바 내부에 완전히 포함)
* 성공 조건: 성공 영역 안에서 정지
* 실패 처리:
  * 실패 메시지 표시
  * 재시도 버튼 (1단계부터 재시작)
  * 나가기 버튼 (탐험 씬으로 복귀)
* 성공 처리:
  * 단계별 성공 시 "Success!" 메시지 표시
  * 카운트다운 (3 → 2 → 1 → START) 후 다음 단계 진행
  * 3단계 완료 시 성공 화면 표시
  * 보상 숫자를 애니메이션과 함께 표시 (파란색 사각형, 흰색 글씨)
  * 나가기 버튼만 표시 (E키 또는 클릭)
* 시각적 요소:
  * 가로 바: 화면 중앙 가로 배치, 화면 너비의 80%, 회색
  * 성공 영역: 노란색, 단계별 크기 (30%/20%/10%)
  * 포인터: 세로선 모양, 높이 100% (바 높이와 동일), 너비 5% (바 길이 기준), 빨간색
* 보상: 숫자 메모 1개

---

### 미니퍼즐 C – 카드 뒤집기 퍼즐 (서버실)

* 화면: 카드 그리드 (직사각형 카드, 모서리 radius)
* 진행 방식: 3단계 순차 진행
  * 1단계: 3×2 그리드 (6장, 3쌍), 시간 제한 5초
  * 2단계: 4×2 그리드 (8장, 4쌍), 시간 제한 4초
  * 3단계: 5×2 그리드 (10장, 5쌍), 시간 제한 3초
* 카드 구성:
  * 도형: 사각형, 원, 삼각형, 별 (4가지)
  * 색상: 빨강, 파랑, 초록, 노랑, 보라, 주황 (6가지)
  * 조합: 도형 + 색상 조합 (예: 빨간 원, 파란 원은 서로 다른 카드)
  * 각 단계마다 필요한 쌍만큼 도형+색상 조합 랜덤 선택
* 규칙:
  1. 게임 시작 전 모든 카드를 앞면으로 1초간 표시
  2. 카운트다운 (3 → 2 → 1 → START, 500ms 간격) 후 모든 카드 뒷면으로 뒤집힘
  3. 카드 클릭 시 앞면으로 뒤집힘
  4. 두 장을 뒤집어 비교
  5. 매칭 성공: 두 카드 모두 앞면 상태로 유지 (클릭 불가능)
  6. 매칭 실패: 두 번째 카드 뒤집은 후 0.3초 뒤 두 카드 모두 뒷면으로 복귀
  7. 비교 중(0.3초)에는 다른 카드 클릭 불가능
  8. 시간 제한 내에 모든 쌍을 찾으면 성공
* 성공 조건: 시간 제한 내에 모든 카드 쌍 매칭 완료
* 실패 조건: 시간 제한 초과 또는 실패 시 재시도 선택
* 실패 처리:
  * 실패 메시지 표시
  * 재시도 버튼 (1단계부터 재시작)
  * 나가기 버튼 (탐험 씬으로 복귀)
* 성공 처리:
  * 단계별 성공 시 "Success!" 메시지 표시
  * 카운트다운 (3 → 2 → 1 → START) 후 다음 단계 진행
  * 3단계 완료 시 성공 화면 표시
  * 보상 숫자를 애니메이션과 함께 표시 (파란색 사각형, 흰색 글씨)
  * 나가기 버튼만 표시 (E키 또는 클릭)
* 시각적 요소:
  * 카드: 직사각형, 모서리 radius, 크기는 화면에 비례하여 단계별 조정
  * 카드 뒷면: 회색 단색
  * 카드 앞면: 도형이 카드 중앙에 그려짐
  * 카드 간격: 적당히 띄워서 배치
  * 카드 위치: 랜덤 배치
  * 타임바: 화면 상단에 시간이 줄어드는 UI 표시
* 보상: 숫자 메모 1개

## 9. 조작 방식 (Controls)

### 플랫폼별 조작 방식

#### 모바일 (Touch)

* **Fixed Virtual Joystick** 사용
* 위치: 화면 좌측 하단
* 구성:

  * 외곽 원: 조작 범위
  * 내부 스틱: 드래그 방향/거리 기준 이동
* 이동 방식:

  * 드래그 방향 → 캐릭터 이동 방향
  * 드래그 거리 → 이동 속도 (아날로그)

> UI 표기 예: 반투명 원형 조이스틱

#### PC (Keyboard)

* 키보드 입력 기반 이동

* 기본 키 매핑:

  * W / ↑ : 위로 이동
  * S / ↓ : 아래로 이동
  * A / ← : 왼쪽 이동
  * D / → : 오른쪽 이동

* 이동 방식:

  * 4방향 또는 8방향 이동 (구현 선택)

#### 공통 규칙

* 모바일 / PC 모두 **동일한 이동 로직** 사용
* 입력 방식만 추상화하여 분기 처리

## 개발 시 참고사항

### 기술 스택
- **게임 엔진**: Phaser 3
- **씬 구조**: 각 방과 퍼즐은 별도 Scene으로 분리
- **상태 관리**: Phaser Scene 간 데이터 전달 (`scene.start()`의 `data` 파라미터 활용)
- **입력 시스템**: PC는 키보드, 모바일은 가상 조이스틱 (공통 이동 로직 사용)

### Virtual Joystick (모바일 이동 컨트롤) 구현 상세

**개요**
- 모바일 환경에서 캐릭터 이동은 Fixed Virtual Joystick 방식 사용
- 화면 좌측 하단에 고정된 원형 조이스틱 UI
- 사용자가 조이스틱을 터치 후 드래그하면 캐릭터가 해당 방향으로 이동

**동작 방식 (중요)**
1. 조이스틱 배경 원(Outer Circle)은 고정 위치
2. 중앙 스틱(Inner Stick)을 터치하면 입력 시작
3. 터치 지점에서 드래그 방향 벡터 계산
4. 드래그 방향 → 이동 방향
5. 드래그 거리(최대 반경 기준) → 이동 속도 (아날로그)
6. 터치 해제(pointer up) 시 이동 즉시 중단

**⚠️ 주의사항**
- 특정 좌표 클릭 이동 방식이 아님
- 항상 드래그 기반 아날로그 이동

### 구현 우선순위
1. 먼저 PC 키보드 입력으로 기본 탐험 가능하게 만들기
2. 조이스틱은 나중에 추가해도 됨
3. 그래픽은 최소한으로 (Rectangle, Circle 등으로 충분)
4. 게임 플로우가 완성되면 시각적 개선
